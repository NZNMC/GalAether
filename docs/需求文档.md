# Galgame 应用商店 · 需求文档 v2

> 状态:**需求已确认,待开工** ｜ 更新:2026-09-27(已加入 ymgal 实测与资源站调研结果)

## 1. 项目定位

- 一款运行在安卓手机上的 Galgame 资源商店 App
- 聚合资源站,支持搜索、浏览、多版本选择下载
- 界面简洁,谷歌原生安卓风格(Material Design 3),主色调可调
- 定位:**个人自用工具**,不上架应用商店、不商业化(资源涉及版权灰色地带)

## 2. 已确认的决定(2026-09-27)

| 事项 | 决定 |
|---|---|
| 爬虫架构 | 纯客户端爬取 + 云端解析规则 |
| 界面技术 | Kotlin + Jetpack Compose,Material 3 |
| 信息库 | 月幕galgame API(官方公开凭据,已实测可用) |
| 数据源 | 一期:鲲galgame + 真红小站;二期:TouchGAL(申请官方接口)✅ 已确认 |
| 下载后处理 | 智能归档 |
| 收藏 | 收藏夹 + 浏览历史 |
| 主题色 | 自定义色轮 + 跟随壁纸自动变色(Material You) |

## 3. 功能需求

### 3.1 浏览与发现

- 首页:最新更新列表、分类入口
- 分类浏览:题材 / 会社 / 标签
- 搜索:按游戏名搜索
- 游戏详情页:封面、简介、截图、标签、大小、发布日期、版本列表

### 3.2 多版本下载

| 版本类型 | 说明 | 下载后处理 |
|---|---|---|
| 安卓直装 | APK | 一键安装(需手动确认) |
| KRKR | 吉里吉里2模拟器数据包 | 自动解压到模拟器目录 |
| ONS | ONS 模拟器数据包 | 自动解压到 ONS 目录 |
| PC | Windows 版压缩包 | 保存到下载目录 |

- 详情页有版本选择框,列出该游戏全部可用版本,选中即下载
- 注:各资源站提供的版本类型不一,选择框里只显示该资源实际有的版本
- 网盘类资源(如百度网盘)无法直接下载,显示为"复制链接 / 唤起网盘 App"

### 3.3 下载管理

- 下载队列、进度显示、断点续传、失败重试、完成通知

### 3.4 收藏与历史

- 收藏夹:收藏游戏,方便以后查找
- 浏览历史:记录看过的游戏,可清除

### 3.5 外观

- **谷歌 Pixel 风格**(Material You / Pixel 设计语言):大圆角、胶囊按钮、柔和配色、简洁留白
- 深色模式
- 主色调:自定义色轮任意选色 + 跟随壁纸自动取色

## 4. 技术方案(概要)

- **信息层**:月幕galgame API——游戏名称(中日文)、封面、简介、标签、发行日期、会社;OAuth2 获取 token,失败自动重新获取;图片走 CDN 并做本地缓存
- **下载层**:纯客户端爬取资源站 + 云端解析规则(JSON,站点改版热更新)
- **界面**:Jetpack Compose + Material 3
- **下载**:断点续传、后台下载
- **智能归档**:APK 走系统安装流程;KRKR/ONS 包自动解压到对应模拟器目录(需要"所有文件访问"权限);PC 版保存压缩包

## 5. 调研结果(2026-09-27,实测)

### 5.1 月幕galgame(ymgal)— 信息库 ✅

- 凭据为**官方公开凭据**(`client_id: ymgal` / `client_secret: luna0327`),已实测成功获取 token
- 接口地址:主域 `www.ymgal.games`,请求需带 `Authorization: Bearer <token>`、`Accept: application/json;charset=utf-8`、`version: 1` 三个头
- 已实测可用:`GET /open/archive?gid=` 游戏详情(返回日文名/中文名/别名/简介/发行商/发行日期等完整数据)
- 待开发期排查:`GET /open/archive/search-game` 列表搜索(接口通,但实测关键词均返回空结果,匹配规则需进一步研究);另有按发行日期、随机游戏、机构、角色等接口
- 封面图存于 `store.ymgal.games` CDN
- 使用规则:**仅限非商业**(本项目自用,符合);有速率限制,需缓存结果、控制频率;项目中需注明"月幕Galgame"
- 无下载链接 → 只做游戏信息库

### 5.2 TouchGAL(touchgal.ink)— 二期,需申请官方接口

- 下载免登录、资源是直链(自建对象存储),**但全站有 Cloudflare 质询,直接爬取返回 403(实测)** → 纯客户端抓取不可行
- 有官方开发者门户,可申请 API token(免费,人工审核)→ 二期路径
- 全站开源:[KunMoe/kun-touchgal-next](https://github.com/KunMoe/kun-touchgal-next)

### 5.3 鲲galgame(kungal.com)— 一期

- 是开源网站(不是加密 App),**无需逆向**,读源码即可拿到全部接口
- 资源页免登录、无 Cloudflare 质询(实测可访问)
- 资源多为**百度网盘链接** → App 只能"显示链接 + 复制/唤起网盘",无法直接下载文件
- 开源仓库:[KUN1007/kun-galgame-nuxt3](https://github.com/KUN1007/kun-galgame-nuxt3)

### 5.4 真红小站(shinnku,即原失落小站)— 一期

- 免登录、**直链下载**、开源([shinnku-nikaidou/shinnku-com](https://github.com/shinnku-nikaidou/shinnku-com))→ 最适合做真正的文件下载

### 5.5 其他

- 初音的青葱:需注册+硬币、网盘链接、大陆需代理 → 不适合
- 社区项目 [SearchGal](https://github.com/Moe-Sakura/SearchGal) 收录了 16+ 免登录直链站(gal.saop.cc 等),后续可低成本扩展

## 6. 版本规划

- **一期(先做出能用的)**:ymgal 信息库(搜索/详情/封面)+ 鲲(资源浏览、网盘链接)+ 真红小站(直链下载)+ 多版本选择 + 智能归档 + 主题色 + 收藏/历史
- **二期**:向 TouchGAL 官方申请 API token → 支持其直链下载;接入更多站点

## 7. 风险与限制

- 版权灰色地带 → 仅自用,不上架、不传播
- 网盘链接(百度/夸克)无法直接下载 → 提供"复制链接/唤起网盘"作为兜底
- Cloudflare 质询的站点无法纯客户端爬取 → 走官方 API 申请或放弃
- 站点改版会导致解析失效 → 云端规则热更新解决
- 安卓高版本存储限制 → 需要"所有文件访问"权限才能写模拟器目录
- ymgal API 有速率限制 → 搜索结果与图片做本地缓存,控制请求频率
