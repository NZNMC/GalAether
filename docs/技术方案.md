## 1. 整体结构

App 内部分为三层:

```
┌─────────────────────────────┐
│  界面层  Compose + Material 3 │  首页/分类/搜索/详情/下载/收藏/设置
├─────────────────────────────┤
│  数据层  Repository          │
│   ├─ 月幕 API(游戏信息)       │  搜索、详情、封面、标签
│   ├─ 资源站爬虫(规则驱动)     │  真红小站(直链)+ 鲲galgame(网盘链接)
│   └─ 本地数据库              │  收藏、历史、下载记录、图片缓存
├─────────────────────────────┤
│  下载层  下载引擎 → 智能归档   │  断点续传、队列、自动解压/安装
└─────────────────────────────┘
```

- **信息层**:月幕 API 提供"有哪些游戏"(名称、封面、简介、标签、发行日期)
- **资源层**:资源站提供"去哪下载"(真红小站直链、鲲的网盘链接)
- **两个来源在详情页汇合**:上面是游戏信息,下面是该游戏各版本下载入口

## 2. 云端规则设计

- 解析规则(JSON 文件)存放在云端仓库(免费,如 GitHub),App 启动时拉取最新规则,本地存一份兜底(断网也能用旧规则)
- 规则内容:站点入口、列表页/详情页解析方式、版本类型识别(从标题或标签识别 APK / KRKR / ONS / PC)
- 站点改版时,只需更新云端规则文件,用户无需重装 App

## 3. 月幕 API 集成要点

- OAuth2 获取 token(grant_type=client_credentials,官方公开凭据),token 失效(接口报错)时自动重新获取
- 所有请求带三个头:`Authorization: Bearer <token>`、`Accept: application/json;charset=utf-8`、`version: 1`
- 游戏详情:`GET /open/archive?gid=`(已实测可用)
- 搜索:`GET /open/archive/search-game`(接口通,但关键词返回空,需开发期排查;兜底方案:按发行日期浏览、官方数据导出)
- 封面图走 `store.ymgal.games` CDN,下载后缓存到本地,避免重复请求(月幕有速率限制)
- 合规:App 内注明"游戏信息来自月幕Galgame"

## 4. 下载引擎

- 基于 OkHttp:多任务队列、断点续传、失败重试、进度回调
- 后台下载:前台服务,锁屏不中断
- 直链资源(真红小站):正常下载文件
- 网盘资源(鲲):显示"复制链接"和"唤起网盘 App"按钮,不做下载

## 5. 智能归档

| 版本类型 | 下载后处理 | 目标位置 |
|---|---|---|
| APK | 调系统安装器(需用户点确认) | — |
| KRKR | 自动解压 | /storage/emulated/0/Kirikiroid2/ |
| ONS | 自动解压 | /storage/emulated/0/ONS/ |
| PC | 保留压缩包 | /storage/emulated/0/Download/GalAether/ |

- 需要"所有文件访问"权限(MANAGE_EXTERNAL_STORAGE),首次启动引导用户开启

## 6. 界面设计(Compose + Material 3,谷歌 Pixel 风格)

- 设计语言:谷歌 Pixel 风格——Material You 动态取色、大圆角卡片、胶囊按钮、简洁留白
- 底部导航:首页 / 分类 / 收藏 / 我的
- 首页:最新游戏(按发行日期)、推荐
- 搜索页:按游戏名搜索(月幕)
- 详情页:封面大图、标题、简介、标签、发行信息 + "版本选择"按钮(底部弹窗,列出所有版本)
- 下载页:下载队列、实时进度、完成通知
- 设置:主题色(色轮 + 跟随壁纸)、深色模式、规则更新、缓存清理

## 7. 本地数据(Room)

- 收藏表、历史表、下载记录表、图片缓存
- 偏好设置:主题色、深色模式

M3 实现说明(2026-09-27,0.3.1 增加下载管理):
- 资源搜索:解析真红小站搜索页(www.shinnku.com/search?q=)内嵌 JSON,免登录
- 下载直链:普通文件 zd.shinnku.top 直链(实测支持 HTTP Range 断点续传);合集系列走站内 /api/r2/download-url/galgame0 跳转
- 多版本:按路径前缀区分 安卓直装(0/apk)/KRKR(0/krkr)/ONS(0/ons)/PC(0/win、zd)/合集,详情页筛选
- 智能归档:APK→通知一键安装;ZIP+KRKR/ONS→解压到 /sdcard/Kirikiroid2 或 /sdcard/ONS(需"所有文件访问"权限,未授权降级为存下载目录);7z/rar 等其他→复制到系统下载目录
- 下载引擎:OkHttp + Range 断点续传,前台服务通知栏进度
- 下载管理(0.3.1):底部新增「下载」标签页,集中管理下载中 / 失败 / 已完成;下载记录持久化,重启 App 不丢失;已完成可 安装(APK)/ 保存到下载目录 / 打开下载目录 / 删除;归档成功后自动删除应用目录里的源文件,不占双倍空间
- 分类浏览(0.3.2):按发行月份浏览(当月往前 24 个月可选),复用月幕发行区间接口
- NSFW 开关(0.3.2):设置页可开关「显示限制级内容」(默认关)。月幕只有发行区间接口带 restricted 字段,搜索/随机接口没有,因此:首页最新发行、分类浏览过滤限制级;随机推荐关闭时隐藏;搜索不过滤

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| 月幕搜索接口规则不明 | 开发期排查;兜底用"按发行日期浏览"+ 官方数据导出 |
| 站点改版解析失效 | 云端规则热更新 |
| 百度网盘链接无法下载 | "复制链接/唤起网盘"兜底 |
| 安卓存储权限收紧 | 引导开启"所有文件访问"权限 |
| 月幕速率限制 | 结果与图片本地缓存,控制频率 |
